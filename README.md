# Tea & Tab

Freelancers flag problem clients, check a client before signing, and talk about it. Pseudonymous, India-first.

- `app/`: Vite + React + TypeScript web app (pixel cream/green look). `cd app && npm install && npm run dev`. Works on built-in mock seeds with no backend.
- `docs/BACKEND_SPEC.md`: routes, rules, and what is not done.
- `docs/WEB_FEED.md`: the curated "from around the web" list, removal requests, and the Reddit candidate finder in `tools/`.

Set `VITE_API_URL` (see `app/.env.example`) to use the real API.
